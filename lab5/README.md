# Lab 5 — HTML & CSS Fundamentals (Part 2)

## Overview
This lab adds four pages demonstrating additional HTML/CSS concepts (links and link-state styling, nested text-formatting tags, nested lists, and tables), all inheriting the shared `base.html` layout built in Lab 4.

## What was implemented
- Task 1 — `/books/html5/links` — three styled links (padding, centered text, block display, distinct colors) with `visited`/`hover`/`active` link states
- Task 2 — `/books/html5/text/formatting` — demonstration of `b`, `strong`, `i`, `em`, `small`, `mark`, `del`, `ins`, `sub` and `sup` tags with a styled heading
- Task 3 — `/books/html5/listing` — nested unordered/ordered lists ("The Best Features of the Internet")
- Task 4 — `/books/html5/tables` — a simple fruit-price table with a totals row, plus a complex table using `rowspan`/`colspan` with an embedded image
