\# Lab 5 — HTML \& CSS Fundamentals (Part 2)



\## Overview

This lab covers core HTML/CSS concepts: links, text formatting, nested lists, and tables.



\## What was implemented

\- `links.html` — styled links with distinct `hover`, `visited`, and `active` states.

\- `formatting.html` — demonstration of text-formatting tags (`b`, `strong`, `i`, `em`, `mark`, `sub`, `sup`, etc.).

\- `listing.html` — nested ordered and unordered lists.

\- `tables.html` — tables using `rowspan` and `colspan` for complex layouts.

\- All pages inherit the shared layout from `base.html`.
